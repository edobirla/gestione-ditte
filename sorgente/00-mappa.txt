GESTIONALE PAVIMASS — file unico, nessuna dipendenza esterna
══════════════════════════════════════════════════════════════════════

Questo file contiene tutta l'applicazione: stile, interfaccia, logica, immagini,
testo del POS e dati di partenza. Si apre con doppio clic (file://) su Mac,
iPhone e iPad. I dati vivono in IndexedDB del browser; il backup è uno ZIP.

Per orientarsi cercare nel file la stringa "SEZIONE" seguita dal nome.

MAPPA DELLE SEZIONI
  CSS   STILE ................ sistema di design (token, temi, componenti, stampa)
  HTML  GUSCIO ............... barra, menu, contenuto, pannello, dialoghi, icone SVG
  JS    UTILITA .............. h() sicurezza HTML, formattazione date/numeri, date, festività, validazioni
  JS    REGOLE ............... funzioni pure: stato documento, scadenza stimata, idoneità, presenze, importi
  JS    STATO ................ stato applicativo, persistenza IndexedDB, esegui/annulla/ripristina, migrazioni
  JS    ARCHIVIO ............. documenti: impronta, deduplica, compressione immagini, anteprime, peso, cestino
  JS    BACKUP ............... ZIP (scrittura/lettura), backup, ripristino, fusione, condivisione
  JS    UI ................... dialoghi, avvisi, tabelle, moduli, pillole, pannello laterale, grafici SVG
  JS    NAVIGAZIONE .......... router #/, menu, ricerca globale, tema, scorciatoie da tastiera
  JS    DASHBOARD ............ semaforo, idoneità, cantieri attivi, mese, clienti, margini, azioni consigliate
  JS    OPERAI ............... elenco, scheda persona, documenti, buste, ore, scadenzario complessivo
  JS    CANTIERI ............. elenco, diagramma temporale, scheda, sei figure, squadra, checklist, economia
  JS    CLIENTI .............. elenco, scheda, referenti, cronologia, andamento, confronto
  JS    PRESENZE ............. griglia mensile, strumenti rapidi, trascrizione, incolla dati, calcoli, uscite
  JS    DOCUMENTI ............ archivio trasversale, buste paga, peso, modelli, generati, caricamento iniziale
  JS    PREVENTIVI ........... listino, editor, incolla da Excel, stampa, esportazioni
  JS    BUDGET ............... movimenti, quote per cantiere, quadratura, riepiloghi, grafici
  JS    IMPOSTAZIONI ......... azienda, backup, peso, tipi documento, modelli, firme, soglie, esportazioni, azzeramento
  JS    STAMPA ............... impaginazione A4 in JS, anteprima, documenti (scadenzario, dichiarazioni, preventivo, libro presenze)
  JS    ESPORTA .............. XLSX, CSV, Markdown, pacchetto committenza, condivisione iOS
  JS    POS .................. procedura guidata, composizione dal testo standard, controllo segnaposto
  JS    PDF .................. estrazione testo dai PDF (inflate in JS), lettura Excel dei clienti
  JS    DATI ................. datiIniziali(): i dati reali di partenza dell'azienda
  JS    IMMAGINI ............. logo, firme, immagini del modello POS (base64)
  JS    POS-TESTO ............ testo standard del POS travasato dal modello aziendale
  JS    AVVIO ................ apertura database, migrazioni, primo render

CONVENZIONI
  - Nomi in italiano. Date in memoria come "AAAA-MM-GG", a schermo "gg/mm/aaaa".
  - Ogni valore inserito nell'HTML passa da h(). Mai concatenare dati grezzi.
  - Ogni modifica dello stato passa da esegui(descrizione, fn): salva e registra per annulla.
  - Le regole di dominio (REGOLE) non toccano il DOM: sono verificabili da sole (vedi autoverifica()).
  - "[DA COMPILARE]" in rosso dove un dato manca: mai inventare valori.
